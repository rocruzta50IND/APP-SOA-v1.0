# Token Architecture Guide
(Extracted from .claude/skills/design-system/references/token-architecture.md)

Three-layer token system:
1. Primitive Tokens: Raw design values.
2. Semantic Tokens: Purpose-based aliases.
3. Component Tokens: Per-component overrides.

Benefits: Scalability, themeability (dark mode), and easier maintenance.
Naming Convention: `--{category}-{item}-{variant}-{state}`.
