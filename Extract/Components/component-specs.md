# Component Specifications
(Extracted from .claude/skills/design-system/references/component-specs.md)

Detailed specifications for core UI components.

## Button
- Variants: Default, Secondary, Outline, Ghost, Link, Destructive.
- Sizes: sm (32px), default (40px), lg (48px).
- States: Default, Hover, Active, Focus, Disabled, Loading.

## Input
- Variants: Text, Textarea, Select, Checkbox, Radio, Switch.
- States: Default, Hover, Focus, Error, Disabled.

## Card
- Variants: Default (sm shadow), Elevated (lg shadow), Outline, Interactive.
- Anatomy: Header, Content, Footer with 24px internal padding.

## Additional Components
- Badge: Success, Warning, Destructive variants.
- Alert: info, success, warning, destructive modes.
- Dialog: sm (384px), default (512px), lg (640px) widths.
- Table: hover, selected, striped row states.
