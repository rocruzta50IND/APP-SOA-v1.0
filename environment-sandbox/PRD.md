# 💎 MASTER PRD (v13.2) - TEMPLATE MANDATE

## 1. PROJECT IDENTITY
- **Project Name:** Aethel CRM / FlowSprint
- **Business Niche:** Marketing & CRM (Enterprise B2B / High-ticket)
- **Target Audience:** Enterprise sales teams managing high-ticket pipelines and email marketing campaigns.

## 2. ARCHITECTURE & TECH STACK
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS, Tier 1 Design (Standard / Functional)
- **UI Components & Icons:** Lucide Icons
- **Data Visualization:** Recharts, Tremor
- **Animations:** Framer Motion (Snappy, high-velocity transitions)

## 3. VISUAL DNA DECISIONS (FAST-TRACK)
- **Color Mode:** Strictly Light Mode (monochrome, high-contrast palette)
- **Typography:** Inter/Geist for Sans, JetBrains Mono for metrics, Black (900) uppercase for headers.
- **Core Styles:** 
  - Sharp corners (0.3rem radius)
  - 1px solid borders, no shadows (Strictly flat aesthetic)
  - Dense, high-information content layouts.
- **Interaction Physics:** Cinematic states (hover: scale-105, active: scale-95), vertical fade-in entrances.

## 4. CORE FEATURES & SCOPE (THE 8-PAGE MANDATE)

### Public Routes
1. **`/` (Landing Page):** High-converting entry point showcasing enterprise B2B CRM capabilities.
2. **`/login`:** Secure entry for enterprise users.
3. **`/register`:** Onboarding flow for new workspaces.

### Internal Routes (Core Modules)
4. **`/dashboard`:** Executive overview. Key Performance Indicators (KPIs) of high contrast using Tremor, showcasing Lead Qualification Rate, Cost Per Acquisition (CPA), and overall pipeline values in USD/EUR. Data visualization via Recharts.
5. **`/leads`:** Lead management and qualification. High-density data tables with actionable status columns. Pipeline tracking for high-ticket conversions.
6. **`/clients`:** Converted lead management. Enterprise portfolio metrics and client health tracking.
7. **`/campaigns`:** Marketing module. Email campaign metrics, ROI tracking, and outbound performance.
8. **`/settings`:** Application configuration, user profile, and workspace management.

## 5. MOCK DATA THEME
- Realistic corporate data focused on enterprise B2B scenarios.
- High-ticket dollar/euro values for sales pipelines.
- Metrics heavily oriented towards marketing efficiency (CPA, conversion rates) and CRM effectiveness.
